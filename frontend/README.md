# FPL Analytics Engine Frontend

React 19, TypeScript, Vite, Tailwind CSS, TanStack Table, TanStack Query, and
Recharts dashboard for the [FPL Analytics Engine](../README.md).

## Commands

Run from `frontend/` (expects the FastAPI backend on port `8000` for `dev`):

```bash
bun install
bun run dev      # Start Vite dev server at http://localhost:5173
bun run lint     # Lint and check formatting with Biome
bun run build    # Type-check with tsc and build with Vite
bun run test     # Run Vitest + Testing Library component tests
```
